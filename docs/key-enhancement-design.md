# 键位增强与统一绑定

主界面的按键视图、动作视图和绑定编辑使用同一工作区。绑定关系保留功能身份、输入条件和保存来源；界面从这些关系展示功能数、状态以及添加、修改、删除与恢复操作。

键位增强控件使用紫色作为统一识别色。开关、额外动作分组、启用提示和统一调度归属使用 `EditorTheme.KeyEnhancement`；关闭或停用的内容保留灰色，待应用更改沿用黄色状态。底栏依次排列键位增强、完美防御 MOD、分隔线、游戏当前方案和应用按钮，高度为 88 个逻辑像素。方案状态与操作提示位于游戏当前方案下方，应用按钮在底栏内垂直居中。底栏标志采用七星剑阵大师兄二阶段倒悬的意象，保留持剑姿态、庄子巾的高方形轮廓与红色牵引丝线，衣料使用银白与暗红。标志位于键位增强内容左侧，高度接近底栏，开关两种状态沿用同一图案，关闭时转为黑白，开启时保留原色。程序式紫焰从窗口客户区底部升起，默认最高覆盖窗口高度的 30%，各簇独立改变高度，普通状态以低簇为主，少数时刻出现高峰，燃烧簇共享供能，强簇同时增加宽度、高度和局部白紫热区亮度。前后火簇通过三层独立反应密度场叠合，各层具有不同的供能分布、上升速度与受风延迟；宽薄焰面内保留透明流纹、亮边和孔隙；根部的小中簇持续交叠，整条底边不出现空白无火带。每簇独立变化，末端沿连续局部流向拉长并收束，轮廓、孔隙和内部流纹一起渐细，再经过短尾焰衰减；燃烧阈值不随高度裁形，熄灭位置错落。火星与焰体使用会话随机种子，窗口尺寸参与簇分布；拖动窗口改变沿高度延迟传输的气流，各簇保留独立惯性，水平偏斜与纵向伸缩逐步消散。火焰不平铺图片，与底栏高度独立，边框同样带有动态燃烧簇。“••• → 界面设置”打开设置弹窗，可启停火焰并调整变化速率、最高高度、整体亮度、透明度和色相。速率默认 75%，高度默认 30%，亮度默认 100%，附加透明度默认 15%，色相默认 0°；速率范围 5%～300%，高度范围为窗口的 5%～100%，亮度范围 0%～300%，透明度范围 0%～100%，色相范围 −180°～180°。亮度和透明度分别整体调整，保留火焰自身的明暗变化。滑杆的连续变化每 60 ms 合并一次，后台仅保留一个在途渲染任务及最新目标设置，由界面定时器呈现完成帧并调度下一帧，计算最多使用四个线程；数组缓冲在场景中复用。颜色调整与界面合成跳过中间透明区域，设备图按当前布局缓存缩放结果。调整即时预览，确定后保存到本机界面偏好；取消恢复打开前的外观，恢复默认仅调整界面外观。火焰帧在后台计算，并按同一窗口客户区坐标，在各界面表面绘制背景之后、文字与图标绘制之前合成；动作表格单元格、空白区和外层留白滚动前后保持对齐；按钮与输入控件保持在前景，不创建独立覆盖窗口，窗口失焦时继续显示与动画，最小化、隐藏、关闭模式或关闭特效时停止。

普通模式的单键写入当前方案和设备的原生存档槽。增强模式使用独立方案库，普通单键同样写入当前方案的运行时覆盖，增强规则及原生输入屏蔽随方案隔离。方案栏、按键视图和动作视图共用现有编辑器；紫色加号和保存预设按钮固定可见。模型、切换和保存约定见[键位增强方案](enhancement-schemes.md)。`IsNative` 表示普通输入关系，`IsRuntimeBinding` 区分运行时覆盖，`ExecutionOwner` 表示执行规划。运行时按当前有效映射逐行决定统一调度、停用、域外原生执行或未覆盖来源，保留原生上下文本身。

普通单键写入原生槽前要求输入与槽所属设备一致；跨设备输入使用增强规则，并在输入设备下展示。重复添加已有普通关系不消耗槽位。整键恢复在原生草稿事务中规划缺失关系，容量不足时增加受支持的增强输出，成功后一起提交增强配置；失败保留原有草稿。预设规划也将溢出输入交给增强配置，预览取消恢复两个来源的检查点。动作恢复只移除当前输入设备的独立规则。

`CustomFunctions` 独立保存自定义输出定义，绑定规则引用相同输出身份。解绑保留定义；删除功能同时移除定义及相关绑定。旧配置中的自定义输出在解绑时保留到定义集合，JSON、预设及 ZIP 沿用同一持久模型。`NormalizeInput` 使保存结果只保留当前触发方式的专用字段；占用列表随当前输入更新，包含脚本监视键。

招式绑定可独立勾选“附加霸体效果”和“附加无敌效果”，位置在前后摇倍率上方，默认关闭。效果使用原厂状态标签，跟随本次能力及其原生后续的生命周期，结束或取消后只移除本次增加的计数；其他绑定及原有 Buff 保留。配置、来源与验证边界见[招式绑定附加效果](binding-move-effects.md)。

`native-input.lua` 从当前有效映射生成原生输入关系，并解析自定义输出，保留一个可重绑名称对应的多个 InputAction 与管线。支持且属于已登记玩法域的映射交给统一调度，原生入口临时屏蔽，避免同一输入执行两次。域外菜单／文本和不支持的来源继续由游戏执行。同一动作、同一设备已有有效运行时映射时，以其管线为准；仅在缺少有效映射时从上下文默认管线补全自定义输出，保留运行时追加的组合依赖与阻断条件。触发器、修饰器从当前原生关系克隆配置，每个来源独立保存可变状态；来源未变时复用克隆。运行时归属日志按动作、按键、执行者与原因记录实际映射，不以复制数量作为覆盖结论。

每条键位增强关系由输入、触发条件与输出组成。支持按下、持续、松开、短按、长按、重复、连按、顺序、轴、开关与自定义识别。输出按原生 InputAction 身份聚合，输入来源保留自己的管线。原生执行归属与关系互斥分别处理：统一调度屏蔽接手的原生映射；suppression 移除指定关系；consume 控制其他关系还能使用哪些物理键。新增绑定默认与其他关系共存，可以仅消费组合中的部分键。消费锁保持到按键实际释放，上下文变化后仍采样已经锁住的键。原生数组重建时只访问当前包装对象，停用或恢复时归还有效原生入口。

默认触发的直接能力与完整招式在按住期间持续请求；游戏原生资格控制实际激活，松开停止后续请求。配置编译保留 `default_trigger`，已有默认能力的 `press` 存储值与显式单次触发分别处理，不改变同规则其他输出的触发次数。直接能力的持续、长按、轴和开关沿有效状态请求；重复、短按、松开和序列沿各自触发时机请求。

输入层不处于 gameplay、界面占用输入、暂停或失去前台时暂停调度并恢复原生入口。恢复时仅键盘移动、摇杆移动和冲刺中满足持续触发条件的管线允许恢复仍按住的输入。攻击、跳跃等非移动输出等待释放后重新触发，避免切回游戏或动作切换时重放离散动作。键盘和鼠标按钮使用独立物理采样，手柄仍依赖引擎原始值。

输入层读取当前本地玩家 CommonUI 子系统的实际模式，并检查文本焦点、光标、暂停和前台状态。剧情、地图及菜单返回后随实际模式恢复，不依赖 Blueprint 输入模式函数的调用记录；游戏原生代码同样可以切换输入模式。

输入映射及其触发器、修饰器通过数组索引读取，上下文 Map 回调只收集上下文对象，退出回调后再读取默认映射。原键记录在写入每条映射前保存，中途失败仍能还原已修改的部分。

绑定条件、倍率准备和输出执行的异常按绑定及目标隔离，同键、其他键及同动作的其他绑定继续执行。延迟招式回调保留触发绑定身份，只清理该绑定拥有的输入和能力。失败后按 1、2、4、8、16、30 秒退避，持续失败时保持 30 秒间隔，相同故障不逐帧记录；后续有效输入可自动重试。共享输入层或清理失败时暂停调度并归还原生输入，冷却后先完成清理再恢复，保留移动恢复和离散动作等待新按键的规则。稳定恢复 30 秒后重置退避；重载配置和更换玩家会重置绑定故障记录。增强关闭时不派发、不准备倍率或读取玩法映射。

能力详情的“保留游戏原有触发方式”独立管理原生组合。`NativeAbilitySuppressions` 编译为 `ability_suppressions`，`native-abilities.lua` 只临时清除匹配的输入触发标签，保留组优先级、资格条件和其他能力。关闭 SpecialDash 的原生触发同时处理 DeflectDash 变体。模块按资产与当前结构地址保存原标签，不保留旧结构包装对象；列表清空、暂停、关闭与重载均恢复仍有效的入口。CL-302256 的 114 个 InputActionBinding 含 907 条触发记录，DebugAbility 全为空；更新后需重新确认直接能力引用。

绑定窗口的“更多设置”提供启用、优先级、逐键占用和输出向量。顺序列表支持每步组合与重排。返回值 hook 通过同一自定义功能入口增删改，同一函数路径只保留一条覆盖，编辑冲突保留原配置。

输入条件通过下拉框选择；自定义触发在原绑定窗口编辑识别器与采样键列表。自定义功能的参数和值从原动作详情修改，保持功能身份及已有绑定，输入条件仍分别归属每条绑定。

功能选择显示人类名称与代码，搜索包含所有语言原生译名及别名。目录目标保留原生名称与武器名，并用语义细节区分具体招式、触发阶段、方向和设备，全部支持 15 种界面语言。原生译名与补充语义保留来源区别。“普通模式动作”只包含普通模式的 21 个存档动作。所有目录目标逐项记录用途分类，4 个方向入口归入移动方向与轴。用途分组覆盖移动、视角与锁定、攻击、攻防闪避、武器、影之武装、饰品、交互道具、场景移动和界面操作；输入阶段与具体能力集中在对应用途下。武器专属招式按原生装备身份和名称归拢；场景操作区分攀爬与行船，界面操作区分菜单、页签、跳过、QTE 和拍照，调试与旧版输入置后。动作视图和功能选择共享分类与层级排序，搜索跨越分组；“全部功能”并列显示完整目录，每组标明包含数量。增强模式首次进入默认选择全部，普通模式默认选择普通动作；刷新和切换模式保留用户当前选择。方向入口保留独立身份与输出向量，替换只拦截指定按键，恢复一个方向保留其他方向的修改。原厂来源 `FactoryKeys` 与可编辑固定关系 `FixedKeys` 分开，额外输入动作不把普通映射伪装成独立绑定。高级功能通过类型控件编辑函数、事件、属性与 hook，结构和数组递归编辑；Lua 用于自定义识别、条件和代码输出。

底部开关放在左侧，负责暂存模式意图。开启后直接使用普通编辑入口；关闭时普通绑定由游戏执行，复杂关系保留并显示停用，仍可直接编辑、添加和整理，开启后统一生效。动作详情和按键详情展示来源、执行规划、原生拦截与关系共存／消耗，键位增强栏悬停列出覆盖范围和具体缺口。模式关闭时不因旧安装残缺自动产生待修复草稿。开关、绑定和配置变更由“应用更改”统一提交；安装成功后，下次启动游戏加载。

存档、原生方案激活和 Mod 安装分别保存结果。前一步成功而后一步失败时，保留失败项意图，重试不重复已经完成的写入。游戏运行时禁止写入游戏存档、切换原生方案及变更组件安装；已加载新版 Mod 时可提交增强方案库并切换。实时应用先由 Mod 校验并确认，随后持久化 JSON 与生成 Lua；拒绝或超时保留草稿，持久化失败时回退到先前实际使用的增强方案。普通动作的修改使用方案内的 NativeBindings，不写入存档槽。离线编辑导出存档与整个增强方案库，不执行安装。

实时编辑复用主程序窗口，Ctrl+Alt+K 呼出置顶编辑器，再次按下隐藏并返回原窗口。绑定先保留草稿，由“应用到游戏 · 无需重启”提交整组更改，不在每次输入时立即执行。窗口化或无边框模式适合单屏操作，独占全屏不能保证保持显示。调度器接管的输入支持额外绑定；保留原生执行的管线只能重用当前已加载的映射数量，容量不足或缺少管线时整组拒绝。

错误在编辑区顶部的紧凑黄色提示卡中显示摘要，背景缓慢呼吸，详情窗口完整展示并支持滚动和复制，底栏不再重复错误。AI / CLI 将用户引导与 Agent 提示词分开，动态带入路径、当前草稿 ZIP 与命令，CLI 使用相同工作区编辑语义，公开目录、键名、配置结构和批量操作，默认只预览；导出、写入存档与实时应用分别明确选择。

ZIP 导出保存存档字节、键位增强配置、生成 Lua、选中方案和默认映射版本。普通“选择存档”入口接受 ZIP，完整校验存档与配置后才替换为离线 session；普通绑定、复杂规则、未知存档字节、选中方案及默认映射规则随包保留。配置无效时当前 session 和草稿不变，导入不执行安装。

配置 JSON 是持久数据源，Lua 是生成物。外部变更与本地草稿发生冲突时保留两者。安装记录自己新建的加载器文件，已有共享加载器、设置和其他 Mod 启用列表保持原样。停用保留配置与加载器；“更多 → 完整卸载键位增强 → 应用更改”移除本工具拥有的文件和启用项。共享加载器只有在由本工具创建、内容未改且没有其他 Mod 使用时移除；未知修改保留并报告。

检测到增强模组需要更新或修复时，主按钮显示“更新增强模组”；游戏运行期间提示先退出，退出后可更新并一并应用待保存设置。安装记录登记过的模组文件有改动时，先将整个模组目录备份到工具备份目录的 `key-enhancement-mod-*.zip`，再替换为随工具提供的文件；配置与方案保留。未登记的文件仍作为冲突保留。错误详情显示在独立整行通知中，不挤占方案和待应用状态。

## 已知边界

独立“点按防御”绑定复用原厂 Deflect 的 Pressed 管线，并同时接入同设备的 Stance 管线。默认按住时交替输出一帧原生短按和一帧释放，循环发起独立防御，松开停止追加；释放帧通过 Stance.Completed 清理 Passive 与架势能力的按下状态。显式单次触发保留一次性语义，连发触发保留配置间隔。防御窗口、连点惩罚与完美判定仍走原厂逻辑，不清零窗口、不添加固定窗口时长。独立“架势状态”保留 Down 管线，按住维持、松开退出，不反复刷新完美格挡窗口。同一动作的原厂来源与增强来源共同参与输入聚合，点按防御不会取消另一来源仍按住的架势。普通“架势/格挡”包含两个输入，保留原厂点按与长按行为；混合输出只对独立防御分支使用短按。

火焰使用 CPU 后台计算，并限制并行度以保留界面操作响应。1860×1260 的离线持久场景在高度 30% 时约 55 ms／帧、高度 60% 时约 73 ms／帧；这些数字只包含造型计算与离线绘制。实际窗口还需要绘制各个控件，大窗口和高火焰范围仍有明显开销。运动 GIF 按模拟时间离线采样，不表示实际窗口帧率。程序式造型仍与游戏参考存在视觉差异。

键位增强默认保留游戏资源资格，绑定可单独选择绕过已支持的资源消费；装备、解锁、目标和动作状态资格仍由游戏判定。输入动作分离不能自动拆开能力内部的架势状态机，目录列出输入可达目标，不表示在任意战斗状态都能发动。鼠标视角增量、滚轮、触板手势、复杂 chord 依赖／blocker 和不支持的动作级时序触发器保留原生执行；手柄独立物理采样及物理恢复尚未覆盖。菜单与文本输入属于域外原生处理，不列为键位增强的玩法覆盖缺陷。

原生时序触发器仅在已证明取消后能正确复位时纳入调度。零值 `UpdateState` 不能通用清除 `RepeatedTap` 的计数，也不能据此推断 `Combo` 或自定义触发器已复位；这些未验证的管线保留游戏执行，并在覆盖说明中列出。

键盘和鼠标按钮使用按帧读取的 `GetAsyncKeyState` 高位电平，不是物理事件队列。完整按下和释放若都发生在两次采样之间，短点击可能漏采；覆盖说明明确列出该采样边界。
