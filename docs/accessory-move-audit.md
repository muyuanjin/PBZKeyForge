# 饰品攻击与条件效果

CL-302256 的开光玉佩鬼火已加入完整招式，可在饮药随机获得鬼火效果、已有待发鬼火且附近存在合法敌人时绑定发射。玉佩、玉佩·改、玉佩·极授予的三个鬼火能力等级共用这一入口。

绑定调用当前玩家已获得且正在运行的鬼火实例上的原生 `Targeting Tick`。该回调搜索 800 范围内的战斗目标，保留敌我关系与原生目标校验，发射 `Pending Ghost Fires` 中已备好的弹体，并清空已使用的槽。持续按键可以持续请求发射；原来的备弹计时器、数量上限、已生成数量和随机效果生命周期继续由游戏管理。

鬼火与吐火是两条不同的资源链。`GA_Accessory_RandomDrink_Lv1` 监听 `GameplayEvent.Medicine.PostActive`，按权重选择效果；鬼火效果授予持续备弹的能力，吐火效果则通过 `BulletGameplayEffectComponent` 和命中效果组件直接执行。毒雾和冲击波也属于饮药随机效果。后几类没有鬼火那样可复用的待发弹体释放阶段，直接施加它们的 GE 会跳过饮药与随机选择。

| 效果 | 实际触发与行为 | 独立入口结论 |
| --- | --- | --- |
| 开光玉佩鬼火 | 随机效果生效后，原计时器备弹，原回调寻找敌人并消耗已有球 | 已支持条件发射 |
| 闪避幻影 | 真实完美闪避消耗事件携带 `DeflectFrameConsumePayload`，按 `Handle` 去重后生成三枚弹体；另一分支校验真实可化解弹体 | 属于原战斗事件的派生效果 |
| 感电连锁 | 原生被动监听 `GameplayEvent.Damage.Taken`，校验真实伤害载荷、玩家来源、雷电伤害原因与冷却/连锁状态 | `OnLightningChain` 是带参数的连锁回调 |
| 点燃连锁 | 原生被动监听 `GameplayEvent.Ability.Accessory.IgniteApplied`，使用真实来源、敌对目标、数值累积和延迟队列 | 属于点燃事件的派生效果 |
| 破势攻击加成 | `GameplayEvent.Damage.Pretake` 中校验玩家来源和目标破势状态，再修改既有伤害倍率 | 属于伤害修饰 |

清点同时读取了 AssetRegistry 中包名含 `Accessor` 的 307 个 Blueprint，解码了其 111 个 Kismet 函数，包含普通 `GameplayAbility`、`SGameGameplayAbility` 和原生被动父类。`DT_Accessory` 的 161 条效果引用沿能力、效果、辅助节点和攻击资源展开后，共得到 301 个包：215 个效果、73 个能力和 13 个攻击资源。其中 66 个饰品能力均在上述 Blueprint 清点内，其余 7 个能力是共用继承基类。引用关系与实际授予组件分别记录，没有以 LegoAbility 类筛选代替饰品清点。

完整包清单、数据表引用闭包、鬼火控制流、原生地址和 15 语言官方饰品名称保存在 [accessory-move-audit.json](accessory-move-audit.json)。角色、装备和其他数据表的来源关系与全游戏能力清点共同核对。

## 已知限制

证据来自当前安装的 cooked 资源与原生程序静态分析。Lua 调度和编译配置已在模拟游戏对象的测试中验证；尚未取得实际游戏战斗运行记录。307 个命名匹配包是已审计子集，不能单独证明全游戏饰品的覆盖完整性。
