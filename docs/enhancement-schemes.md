# 键位增强方案

## 方案与界面

普通模式与键位增强共用方案栏、按键视图、动作视图和绑定编辑器。普通模式编辑游戏存档中的默认预设、自定义 1、自定义 2；增强模式编辑程序独立保存、由 Mod 执行的方案。增强方案数量不受游戏槽位限制。

方案使用横向标签直接展开。普通模式显示原生三个方案，右侧加号置灰；增强模式显示独立方案列表，加号使用紫色样式。标签放不下时提供横向滚动及更多方案入口；加号和“保存为预设”固定可见。新建方案从当前方案复制，命名后立即选中，额外方案支持重命名和删除。

选中标签表示正在编辑；游戏实际使用的方案在底栏显示。编辑和切换分别操作，浏览方案不改变游戏输入。未应用修改在标签上标记。两种模式分别记住编辑位置，关闭增强后使用原生方案，重新开启时保留增强配置。

## 独立配置

首次建立增强方案时从原生三个方案复制有效键位，并保留已有增强配置。之后独立编辑，不持续继承原生方案。默认预设、自定义 1、自定义 2 在增强模式中同样由程序模拟，与新增方案使用同一执行机制。

每套方案保存普通动作的完整运行时键位、增强规则、原生关系屏蔽及能力输入屏蔽。普通单键在增强模式中写入运行时配置，不写原生存档。绑定默认作用于当前方案；自定义功能定义和全局脚本、hook 保持安装级配置，资源 Mod 与加载器状态独立管理。

编辑器草稿与已部署配置分开。应用当前方案时部署完整配置并切换；游戏内切换仅使用已部署版本。运行时报告实际方案身份，增强方案启用不依赖原生存档的方案选择，也不改写共享设置。

## 实时切换

方案库随配置交给 Mod，支持绑定到指定方案及上一套、下一套。切换入口作为共用管理绑定，不随当前方案消失，编辑器关闭后仍可切换。

切换先结束旧方案持续输出、清除识别状态并恢复旧的原生拦截，再装载目标方案。仍按住的离散输入须释放后才能再次触发；移动与冲刺按现有持续输入恢复规则处理。切换键在释放前不能再次触发切换。目标配置无法执行时保留原方案并报告原因。

## 保存与预设

“保存为预设”是方案栏常驻按钮，保存当前选中方案的完整草稿，无需先应用。窗口允许输入新名称或选择已有用户预设，更新已有目标前明确确认；再次保存预填上次目标。预设保留现有设备范围选择，并包含对应普通键位、增强绑定和输入设置。

JSON 为持久数据源，Lua 为生成配置。方案库随配置导出、导入并持久保存；单方案预设与分享保留当前方案的内容。原有单份增强配置导入后保留其绑定与行为。

## 验证

验证不同方案的普通键位、增强规则和屏蔽互不影响，增强编辑不修改原生存档，模式切换保留两边草稿，新建与删除的方案可持久保存和导出重开。验证运行时切换、按住切换键不连跳、旧持续输出释放、离散输入不重放及拒绝目标后的旧配置恢复。通过截图检查标签展开、溢出访问、加号及预设按钮可见性。

原生方案的认证读写继续使用既有测试；运行时模拟测试与真实游戏行为分别记录。
