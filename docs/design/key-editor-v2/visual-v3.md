# 官方壁纸主题

本版替换旧浅灰／琥珀视觉，沿用 [交互契约](design.md)。以实际 WinForms 程序截图验收，不能用生成概念图替代运行结果。

## 画面与品牌

- 使用维护者提供的官方游戏壁纸（红色祈愿树、侠客）制作高清背景。保持主体比例，裁掉底部黑色信息条；主画面覆盖窗口，暗色渐变保证文字清楚。上方品牌区保留可辨识的官方画面，不能把背景压成看不见的纯色。
- 顶部左侧展示透明官方中文标识，配小号 `PBZKeyForge / 键位设置`。已有剑与键帽图案制成适合暗背景的透明应用标记，尺寸控制在 40–48 个逻辑像素；不再出现米色方块底图。
- 右侧语言、刷新、更多与标题形成同一条基线。品牌区约 96–112 个逻辑像素，主内容不扩成大幅海报；窗口缩小时优先保留绑定列表可用高度。

## 色彩与控件

- 窗口底色墨黑 `#101315`，数据面板 `#191D20`，浮层 `#22272B`，细线 `#343A3D`；主文字米白 `#EEEAE1`，说明文字 `#ADB2B1`。壁纸主要出现在品牌区和内容外围，数据区使用足够实的深色底。
- 主按钮朱砂红 `#AD363B`，悬停 `#C44A4E`，白字；禁用为低对比石墨灰。刷新等次级操作为深色描边按钮，图标与文字垂直居中；圆角约 5 个逻辑像素，统一边框、留白、hover、pressed、focus 状态。
- 语言、刷新、更多具有相同视觉高度、顶边和中轴线。底部“撤销更改”使用与“应用更改”等高等宽的次级描边按钮，两者基线、圆角、间距一致；“应用前自动备份”单独占完整一行，底栏按实际 DPI 预留足够空间，不能在按钮下被裁切。
- 最外层标题栏和细边框使用同一暗色主题。最小化、最大化／还原、关闭等宽等高，并位于独立的一排；不与语言、刷新、更多混排。保留拖动、调整大小、最大化不遮挡任务栏、还原、双击标题栏、系统菜单和键盘关闭的窗口行为；在本机 150% 缩放下验收。
- 方案和设备页签使用深色底、细红色选中线。游戏当前徽标用中性浅灰绿色，与选中和未保存标记各自独立。红色在本主题中表示强调；错误另用文字／图标说明，不能单靠色彩区分。
- 表格去掉每格白色输入框和密集棋盘边框。使用固定表头、深色行面、低对比横分隔线与轻微交替底色；绑定呈紧凑深色键帽，鼠标悬停边线变亮，修改后用红色边线／左侧标记配暖色底。默认值与具体绑定保持可读的明度差。
- 动作列表头和行文字左对齐；三个绑定列表头分别居中对准下方键帽的实际中心，左右内边距相等。固定表头跟随正文列宽及滚动条占位，不能靠整行等分近似对齐。
- 绑定弹窗、下拉框、更多菜单、复选框与主界面共用暗色主题；弹窗中的主要／次要操作角色一致。可用 WinForms 的 owner draw 和系统菜单行为，避免白色原生控件散落在深色面板上。

## 命名与清晰度

- 启用项写“设为游戏当前方案：「自定义 1」”，点击应用后保存；所有语言都不把操作命名为“下次启动”。运行中就地写“游戏运行中，退出后可应用”，保留草稿编辑。
- 程序声明 System DPI awareness；以 96 DPI 为布局基准，在实际 144 DPI（150%）直接绘制字体和控件。自绘坐标、边框、圆角和图像均按实际 DPI 计算；不依赖 Windows 整窗位图放大。
- 语言至少覆盖游戏实际支持的语言列表，并记录列表来源。验收实际 EXE 的 100% 与本机 150% 截图，包含最小窗口、当前／待启用、当前方案键鼠／手柄、修改、冲突、重置和游戏运行状态。常规检查使用简体中文；全部语言的布局与文案检查仅在针对性本地化测试时启用。固定表头边界与正文一致，关键操作及目标方案不可截断；文字与细线保持清晰。
