[color=#e8b96a][b]YOUR CONTROLS, MORE MOVES, LESS REPEATED RUNTIME WORK[/b][/color]
Build the keyboard or controller layout you want: combine attack and guard on one key, bind extra weapon moves independently, and choose how each move behaves. Version 1.3.1 expands the move selection, fixes independent activation and reduces repeated work during play. Ordinary shared-key editing needs no runtime loader.

Windows editor with ordinary save editing and optional Key Enhancement. Ordinary bindings need no loader; Key Enhancement includes the pinned Kintaro PBZ UE4SS runtime. Open source; release downloads are built and uploaded by GitHub Actions.

[color=#e8b96a][b]DOWNLOADS AND INSTALLATION[/b][/color]
[list=1]
[*]Close the game completely. Back up [b]ProjectPBZ/Saved/EnhancedInputUserSettings.sav[/b].
[*][b]Main download:[/b] extract the archive and run PBZKeyForge.exe. It finds your save automatically. Choose Default, Custom 1 or Custom 2, then edit bindings or preview a preset.
[*]Click [b]Apply changes[/b] to save. Check [b]Set game scheme to…[/b] if you also want to make the edited scheme active. Writes are backed up automatically.
[*][b]Key Enhancement:[/b] enable the footer switch and apply with the game closed, then restart the game. Once the Mod connects, binding edits can be applied live. First installation, enabling/disabling and runtime updates require the game to be closed.
[*][b]Presets-only download:[/b] choose one file using PRESETS.md, copy it over EnhancedInputUserSettings.sav, then select [b]Custom 1[/b] in game. This replaces your saved layouts; use the editor when you want to keep and combine existing custom settings. The presets-only archive contains no executable or gameplay mod.
[/list]
The editor remembers the last opened save and follows Steam's installation records to find the game. Switching schemes reads the latest settings. Refresh preserves drafts and asks you to resolve conflicting changes. Both editing views share the same draft; switching views does not save it.

[b]No game or save yet?[/b] The editor opens an offline scheme with built-in factory bindings. Keyboard/mouse, Xbox and PlayStation are available even if no controller has ever been connected. Choose Controller, then Xbox or PlayStation to edit each family independently. Save or share through Preset manager, or use [b]Export game bindings[/b] in the footer to create a .sav file. You can also start with [b]More → New offline scheme[/b]. Open your own save when you want to apply directly to the game.

[color=#cc4125][b]IMPORTANT[/b][/color]
[quote][b]Do not apply or reset bindings in the game's own key binding screen afterwards.[/b] The game rewrites these settings. If this happens, reapply your layout with PBZKeyForge.[/quote]
Copying a preset save replaces your saved layouts. Ordinary shared keys trigger several actions together; Key Enhancement adds timed triggers and independent move bindings. Complete moves use the game's native preparation. Supported restrictions can be bypassed per binding; real targets, hit results and required gameplay objects still apply.

[color=#e8b96a][b]SEE AND EDIT YOUR BINDINGS[/b][/color]
[b]By key:[/b] click a key on the keyboard, mouse or controller diagram to see and edit its actions on the right. The keyboard and mouse appear together. Number badges count actions: gray matches factory settings, blue marks saved customization, and yellow marks edits waiting to be applied. Removed actions are gray and crossed out.

[b]Whole-scheme comparison:[/b] the bottom panel compares the whole scheme with your saved settings or factory defaults. Additions appear first, retained keys follow, and gray crossed-out removals come last. Click the binding content to cycle through combined bindings, changes only, results and original bindings.

[b]By action:[/b] browse the grouped action catalog, edit bindings and see their actual factory keys. Ordinary mode uses the game's native slots; enhancement adds further bindings and trigger types. Both views share the same draft.

[b]Default or Unbound:[/b] Default shows the actual factory key and restores it. Unbound explicitly removes the slot's binding. You can choose a key from the list or focus the capture field and press a keyboard or mouse button.

The interface supports all 15 game languages, including Simplified and Traditional Chinese. Switch languages from the toolbar. Keyboard/mouse, Xbox and PlayStation are supported. The gallery shows complete PC, Xbox and PlayStation key views, followed by the extra-action catalog, in English and Simplified Chinese.

[color=#e8b96a][b]OPTIONAL: PERFECT GUARD WITHOUT THE RAPID-CLICK PENALTY[/b][/color]
Repeated guard inputs shorten or stop refreshing the original perfect-guard window. When attack and guard share a key, repeated attacks can trigger the same penalty.

The [b]Perfect guard: no rapid-click penalty[/b] option is [b]off by default[/b]. Check it on the right side of the footer, then click [b]Apply changes[/b] to install. The checkbox only stages the change. Click [b]?[/b] for an explanation. All schemes, difficulties and guard keys share this gameplay change. Each input still uses the game's current base perfect-guard window; difficulty, accessories, guard-break state and eligibility follow the original rules.

The embedded patch changes one cooldown value in each of five difficulty configuration assets and preserves the game's combat scripts. It installs in its own Paks/~mods/PBZKeyForge_PerfectDeflectNoRapidClickPenalty folder without replacing original game containers or saves. [b]Exit the game before enabling or disabling it.[/b] Uncheck the option and apply to remove it and restore the original rules. The presets-only archive does not include this mod.

[color=#e8b96a][b]COMPATIBILITY AND UNINSTALL[/b][/color]
Windows 10/11, Steam launch build [b]CL-301524[/b] and patch [b]1.0302256 / CL-302256[/b]. Keyboard/mouse and controller bindings use the installed build's slot rules, including Phantom Edge's changed slots in 1.0302256. Existing preset layouts and PBZ2 share codes keep the same baseline. Compatible later-build scheme settings can be discovered and authenticated locally in the background; later input-rule changes may still need an update.

Restore your save backup to remove ordinary binding changes, or preview and apply [b]More → Restore all defaults[/b]. Disable Key Enhancement and apply with the game closed to stop its runtime; use its [b]•••[/b] menu for full uninstall. Configuration is retained outside the Mod folder for later use. Shared loaders and other Mods are preserved. Remove the perfect-guard option separately by unchecking it and applying with the game closed.

[color=#e8b96a][b]KNOWN LIMITS[/b][/color]
The optional gameplay patch uses Steam 1.0302256 difficulty assets and conflicts with mods replacing the same assets. A new game patch may require an updated mod.
Key Enhancement targets Steam CL-302256 with UE4SS v3.0.1-1195-g1ceefac8 and requires Microsoft Visual C++ v14 x64. The editor checks its dependencies before installation. Combat behavior may conflict with Mods changing the same inputs or abilities. Automated tests cover input routing and recovery; they do not establish in-game FPS or every move's combat behavior.
