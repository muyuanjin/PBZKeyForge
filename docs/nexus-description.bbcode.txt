[color=#e8b96a][b]ONE KEY, SEVERAL ACTIONS[/b][/color]
Phantom Blade Zero's binding screen rejects shared keys. PBZKeyForge edits the game's own settings file so a single key can trigger several actions: attack and guard together, dodge on your former guard button, or your own keyboard and controller layout.

Single-file Windows app. No installer, mod loader, DLL injection or extra runtime download. Open source; release downloads are built and uploaded by GitHub Actions.

[color=#e8b96a][b]SEE AND EDIT YOUR BINDINGS[/b][/color]
[b]By key:[/b] click a key on the keyboard, mouse or controller diagram to see and edit its actions on the right. The keyboard and mouse appear together. Number badges count actions: gray matches factory settings, blue marks saved customization, and yellow marks edits waiting to be applied. Removed actions are gray and crossed out.

[center][b]Keyboard and mouse: one key can have several actions[/b]
[img]https://staticdelivery.nexusmods.com/mods/10614/images/402/402-1793738867-1951931963.png[/img][/center]

[center][b]Controller: select a button to see its actions[/b]
[img]https://staticdelivery.nexusmods.com/mods/10614/images/402/402-1793738868-1612295116.png[/img][/center]

[b]Whole-scheme comparison:[/b] the bottom panel compares the whole scheme with your saved settings or factory defaults. Additions appear first, retained keys follow, and gray crossed-out removals come last. Click the binding content to cycle through combined bindings, changes only, results and original bindings.

[b]By action:[/b] edit each function's bindings and see its actual factory keys. The interface shows the available slots and explains when an action cannot accept another key. Both views share the same draft.

[center][b]By action: factory keys and editable binding slots[/b]
[img]https://staticdelivery.nexusmods.com/mods/10614/images/402/402-1793738862-1212036742.png[/img][/center]

[b]Default or Unbound:[/b] Default shows the actual factory key and restores it. Unbound explicitly removes the slot's binding. You can choose a key from the list or focus the capture field and press a keyboard or mouse button.

[center][b]Choose a key, inherit its factory value, or unbind it[/b]
[img]https://staticdelivery.nexusmods.com/mods/10614/images/402/402-1793738864-209796483.png[/img][/center]

The interface supports all 15 game languages, including Simplified and Traditional Chinese. Switch languages from the toolbar. Chinese screenshots are available in the expandable section below.

[color=#e8b96a][b]YOUR PRESETS AND SHARE CODES[/b][/color]
Open [b]Preset manager[/b] next to Quick setup. Enter a name in the highlighted field, then choose [b]Save as preset[/b] to save the current scheme, including unapplied edits. Personal presets are separate from built-ins. Select one to preview it; check several to delete them without changing your current bindings.
[center][b]Name your current scheme, then save it as a preset[/b]
[img]https://staticdelivery.nexusmods.com/mods/10614/images/402/402-1793738880-115553500.png[/img][/center]


Copy a named, one-line share code for all included devices, keyboard/mouse, controllers or one controller family. The character count updates with your choice. Select a saved preset to preview its factory differences; check presets in the library to delete them.
[center][b]Share all devices, keyboard/mouse only, or one controller family[/b]
[img]https://staticdelivery.nexusmods.com/mods/10614/images/402/402-1793738883-1481743152.png[/img][/center]

Paste a share code, click [b]Preview[/b], and inspect the included devices and changes before saving or using it. [b]Save to my presets[/b] keeps it in your library; [b]Save and use[/b] also stages it in the current scheme. [b]Export game bindings[/b] creates a game settings file containing your current scheme's edits.

[color=#e8b96a][b]CHOOSE HOW A PRESET CHANGES YOUR KEYS[/b][/color]
Three choices stay visible beside the preset picker. Hover over a choice for details.
[list]
[*][b]Add keys:[/b] keep existing keys and add the preset's bindings; duplicates are ignored.
[*][b]Replace keys:[/b] replace the bindings of the actions covered by the preset; other actions stay as they are.
[*][b]Preset only:[/b] start from factory bindings for the devices included in the preset, then use that preset's layout. Devices outside its scope keep their settings.
[/list]
The initial choice is Preset only, and your choice is remembered. Selecting a preset creates a draft. [b]Apply changes[/b] writes it to the game. Applying shows a spinning progress indicator; if a write fails, your draft remains available to retry.

[color=#e8b96a][b]BUILT-IN LAYOUTS[/b][/color]
[list]
[*][b]Left mouse also guards:[/b] add guard to left mouse / X while keeping right mouse / LB and existing guard keys.
[*][b]Left light, right heavy; both guard:[/b] left click is light attack + guard; right click is heavy attack + guard. F remains heavy attack. Keyboard/mouse only.
[*][b]Dual-button combat + Auto sprint:[/b] the same mouse layout, plus W/A/D sprint and Space dodge + jump. F retains heavy attack; Shift retains dodge. Shift and Space no longer trigger sprint. Keyboard/mouse only.
[*][b]Left attack + guard, right dodge:[/b] move guard to left mouse / X and use right mouse / LB for dodge + sprint.
[*][b]Souls gamepad layout:[/b] light attack RB, heavy RT, guard LB, dodge/sprint A, interact/execute Y.
[*][b]Space to sprint / Space to dodge:[/b] add Space to the selected action while retaining Shift.
[*][b]Restore factory defaults:[/b] restore the selected scheme in Quick setup, or all schemes through More.
[/list]
The included [b]PRESETS.md[/b] lists the factory-based layouts used by the eight ready-made settings files. Add keys mode can retain additional existing bindings; the hover preview shows the preset relative to factory settings.

[color=#e8b96a][b]DOWNLOADS AND INSTALLATION[/b][/color]
[list=1]
[*]Close the game completely. Back up [b]ProjectPBZ/Saved/EnhancedInputUserSettings.sav[/b].
[*][b]Main download:[/b] extract the archive and run PBZKeyForge.exe. It finds your save automatically. Choose Default, Custom 1 or Custom 2, then edit bindings or preview a preset.
[*]Click [b]Apply changes[/b] to save. Check [b]Set game scheme to…[/b] if you also want to make the edited scheme active. Writes are backed up automatically.
[*][b]Presets-only download:[/b] choose one file using PRESETS.md, copy it over EnhancedInputUserSettings.sav, then select [b]Custom 1[/b] in game. This replaces your saved layouts; use the editor when you want to keep and combine existing custom settings. The presets-only archive contains no executable.
[/list]
Switching schemes reads the latest settings. Refresh preserves drafts and asks you to resolve conflicting changes. Both editing views share the same draft; switching views does not save it.

[color=#cc4125][b]IMPORTANT[/b][/color]
[quote][b]Do not apply or reset bindings in the game's own key binding screen afterwards.[/b] The game rewrites these settings. If this happens, reapply your layout with PBZKeyForge.[/quote]
Only one mod replacing EnhancedInputUserSettings.sav can be installed at a time. Shared bindings trigger multiple actions; this tool does not add timed input sequences or guarantee a particular combination skill.

[color=#e8b96a][b]COMPATIBILITY AND UNINSTALL[/b][/color]
Windows 10/11, Steam CL-301524. The tool supports keyboard/mouse and controller bindings. Game updates may require new defaults or scheme-activation support. Restore your backup to uninstall, or preview and apply [b]More → Restore all defaults[/b] to return to factory bindings.
