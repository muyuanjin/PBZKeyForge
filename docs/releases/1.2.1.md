# PBZKeyForge 1.2.1

Changes since [v1.2.0](https://github.com/muyuanjin/PBZKeyForge/releases/tag/v1.2.0).

- Added offline scheme creation from the embedded factory baseline. Editing, personal presets, scoped sharing and game-file export no longer require a game installation or input save. The footer offers export in offline mode; direct application remains available after opening a game save.
- Xbox and PlayStation are always selectable, including saves with no controller records or no controller property. Family edits remain independent. Missing records are materialized only when needed for an edited export or application, preserving unrelated records and metadata.
- Matched PlayStation records and compact share-code family IDs to the game's canonical `PS` identity. Native family normalization and projection evidence is documented in the Mod development skill.
- Fixed the device canvas overlapping its instruction bar and obscuring controller shoulders. Added layout assertions at regular and minimum window sizes.
- Updated bilingual screenshots to use the real offline editing entry and controller selector. Capture no longer needs an installed game or a demonstration save.

Validation covers offline creation, absent/empty controller records, Xbox/PS isolation, scoped sharing, export/reopen, unchanged source data, UI controls and fixture serialization. These checks do not establish physical controller input behavior in game. Supported factory data remains Steam CL-301524.

The main download includes the editor and eight preset files. The presets-only archive includes the same layouts and bilingual guide without an executable. Close the game before applying or replacing settings; select Custom 1 in game when using a packaged preset file.
