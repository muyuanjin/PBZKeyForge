# PBZKeyForge 1.3.2

Changes since [v1.3.1](https://github.com/muyuanjin/PBZKeyForge/releases/tag/v1.3.1).

- **Search moves by what you know:** enter weapon, move, upgrade or technical names as separate terms in any order. Each official name shared by one action is its own selectable row, while adding several of those names still creates one underlying output.
- **Attack insight:** inspect physical or elemental damage coefficients, poise coefficients, conditional ranges and timeline attack nodes before binding a move. Search also finds these values. The tooltip separates coefficients from final health damage and attack nodes from actual hit counts.
- **Review preset loads:** preview saved presets and review the target scheme, binding changes and effects on scripts, input blocks and other settings before loading.
- **More reliable editing:** preserve explicit stance and combined-guard eligibility, keep paired Deflect state independent, and retain edits made to an inactive enhancement scheme.
- **Runtime and interface fixes:** stabilize player-session recovery, scheme menus, window restoration and deployment comparison; speed up action views and debounce catalog searches.

## Downloads

Extract the main archive and run PBZKeyForge.exe. Close the game before changing or updating the enhancement runtime, then restart the game. The presets-only package contains the same eight ordinary save layouts as v1.3.1, without the editor or enhancement runtime. Select **Custom 1** after copying a packaged save.

## Validation and limitations

Regression checks cover search ranking and caching, all 15 languages, shared action names, attack-insight coverage for all 1,250 bindable moves, preset review, scheme-scoped editing, runtime recovery and the complete binding workflow. Release checks require byte-identical save round trips and preset equivalence.

Attack coefficients come from BulletData referenced by each move's timeline; ranges combine native conditional branches. They are not final per-hit health damage and the node count is not an actual hit count. Enhanced combat targets Steam CL-302256 and UE4SS `v3.0.1-1195-g1ceefac8`; ordinary save editing also supports CL-301524. Automated models do not establish every move's animation, damage or target behavior in actual combat.
