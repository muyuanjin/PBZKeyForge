# PBZKeyForge 1.2.3

Changes since [v1.2.2](https://github.com/muyuanjin/PBZKeyForge/releases/tag/v1.2.2).

- **Optional perfect-guard change.** The footer now offers **Perfect guard: no rapid-click penalty**, off by default. Check it and click **Apply changes** to install; uncheck and apply to remove it. It removes the penalty from repeated guard inputs, including attacks when attack and guard share a key. All schemes, difficulties and guard keys share the change. Each input still uses the game's current base timing, difficulty, accessory and guard-break rules.
- **Steam patch 1.0302256 support.** Scheme activation and binding editing support both `CL-301524` and `CL-302256`. Phantom Edge slots follow the installed build's rules: the newer build's mirrored keyboard slot is read-only, and its controller bindings use two independent slots. Existing built-in layouts and PBZ2 share codes retain their baseline.
- **More reliable save discovery.** The editor remembers the last opened save and reads Steam installation records instead of relying on the default folder name. Compatible scheme-setting readers can be discovered locally in later builds; first-time discovery runs in the background and preserves edits confirmed in an open binding dialog.
- **Faster editing.** Startup, device and scheme refreshes, preset hover previews, and personal-preset operations do less repeated work.
- **Clearer layout and application feedback.** Keyboard/mouse diagrams and action tables fit smaller windows better, the interaction icon is refreshed, and scheme-comparison rows stay clipped while scrolling. Apply explicitly asks you to exit a running game, keeps its busy appearance during writes, and avoids flashing a spinner for brief saves.

The gameplay patch changes only `Deflect Quickclick Punish Cooldown` from `0.4` to `0` in five difficulty configuration assets. Combat scripts and all other package bytes are preserved. Installation uses embedded resources in a separate `Paks/~mods/PBZKeyForge_PerfectDeflectNoRapidClickPenalty` folder; original game containers and saves are not replaced. Close the game before enabling or disabling it.

Validation covers authenticated scheme changes and binding edits on copies from both supported builds, native slot rules, and visible-window layout and responsiveness. Release checks passed 109 share-code, 5,558 preset-package and 97 offline-editing assertions, with `roundtrip=IDENTICAL`. All four embedded gameplay-patch resources match in both executables; English and Simplified Chinese layout checks each passed 19 assertions. Offline patch checks cover the five changed values, preserved package data and isolated installation/removal.

## Downloads

The main archive contains the editor and eight ready-made preset files. The presets-only archive contains the same eight layouts as 1.2.2 with updated documentation; it includes neither an executable nor the optional gameplay patch. Close the game, back up your settings, and select **Custom 1** in game after copying a packaged preset.

## Known limitations

The new numeric gameplay patch has not yet been verified for in-game loading or combat stability. Its source assets are from Steam 1.0302256 / `CL-302256`; other mods replacing the same difficulty assets conflict with it. Resource detection does not establish compatibility with future game updates. Later-build scheme discovery requires the supported key-derivation instructions and PBZS format; authentication alone does not establish that a later build uses the same input rules. See [game compatibility](https://github.com/muyuanjin/PBZKeyForge/blob/v1.2.3/docs/game-version-compatibility.md) and [gameplay patch details](https://github.com/muyuanjin/PBZKeyForge/blob/v1.2.3/docs/perfect-deflect-no-rapid-click-penalty-mod.md).
