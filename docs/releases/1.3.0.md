# PBZKeyForge 1.3.0

Changes since [v1.2.3](https://github.com/muyuanjin/PBZKeyForge/releases/tag/v1.2.3).

- **Key Enhancement:** optional runtime bindings for chords, tap/hold, repeated presses, sequences and additional actions. Keyboard/mouse, Xbox and PlayStation use the same key and action editors.
- **Independent enhancement schemes:** copy, rename and switch layouts, including switching through bindings while the editor is closed. Presets and share codes include enhancement bindings; ZIP exports preserve the scheme library.
- **Complete moves:** bind weapon attacks, Combat Art finishers, charged releases, Phantom Edge attacks and conditional follow-ups separately. Equipment, upgrades, targets and native activation requirements still apply.
- **Per-binding combat settings:** optional resource bypass, health-damage multipliers and startup/recovery speed. Each activation keeps its own settings, including its projectiles and native follow-up abilities.
- **Live editing:** after installation and game restart, apply binding edits without leaving the game. Connection status, full error details and rollback keep failures visible and drafts available. Disabling enhancement retains its configuration for later use.
- **Runtime performance and recovery:** reuse input plans and object buffers, install tuning hooks when needed, isolate failing action targets and retry incomplete cleanup. Improved editor refreshes, small-window layouts and live binding dialogs; fixed action-group text flickering during enhancement animation.
- **CLI workflows:** discover actions, preview and batch-edit bindings, exchange schemes, and manage the optional Mods from the command line.

## Downloads

The main archive includes the editor, CLI, documentation and eight ready-made preset saves. Key Enhancement includes the pinned Kintaro PBZ UE4SS runtime; enable it and apply with the game closed, then restart the game. The presets-only archive contains ordinary save layouts and instructions, with no executable or enhancement runtime. Its eight layouts are unchanged from 1.2.3. Select **Custom 1** in game after copying a packaged save.

## Validation and limitations

Release checks cover save round-trip identity, preset equivalence, sharing, CLI workflows, runtime installation and coexistence. Lua and native bridge regressions cover binding ownership, damage attribution, deferred execution and cleanup retries. UI captures cover English and Simplified Chinese.

The release pins UE4SS `v3.0.1-1195-g1ceefac8` and targets Steam `CL-302256` for enhanced combat behavior. Ordinary save editing also supports `CL-301524`. Game updates or Mods replacing the same inputs and combat resources may require adaptation. Automated checks do not measure in-game FPS or prove every move in actual combat. The separate perfect-guard penalty option remains off by default.

## 中文摘要

- 新增可选键位增强：组合键、短按／长按、连按、顺序输入及额外动作，支持键鼠、Xbox 和 PlayStation。
- 增强模式使用独立方案库，可复制、重命名，也可通过绑定在游戏内切换；预设和分享包含增强绑定，ZIP 保存整个方案库。
- 武器招式、战技末段、蓄力释放、影之武装攻击和条件追击可分别绑定，保留装备、修行、目标及原生激活条件。
- 每条绑定可设置资源绕过、生命伤害倍率及前后摇速度，本次施放的弹体和原生后续保留对应参数。
- 安装并重启游戏后支持实时修改绑定；连接状态、完整错误详情和回滚保留失败信息与草稿。关闭增强后保留配置。
- 减少调度和界面刷新中的重复工作，按需接入调参，隔离失败目标，保留未完成清理供重试。提供 CLI 批量编辑和 Mod 管理入口。

仅预设包的八个布局与 1.2.3 相同，不含增强运行时。自动化验证不代表实机帧率或全部招式的战斗验证。
