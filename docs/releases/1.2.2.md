# PBZKeyForge 1.2.2

Changes since [v1.2.1](https://github.com/muyuanjin/PBZKeyForge/releases/tag/v1.2.1).

- Faster startup: save discovery and authentication run alongside interface construction. The window appears with the session and controls ready, eliminating the language selector appearing before the rest of the editor.
- Reduced layout work, deferred Xbox and PlayStation artwork until first use, and optimized image drawing.
- Faster interface refreshes through fewer binding scans and sorts. Buffered executable reads reduce the cost of build authentication.

Local three-run measurements with filesystem caches warm: startup reached a median of approximately 0.63 seconds, compared with 1.40 seconds before optimization. These measurements cover the editor's first idle state on one Windows machine.

Validation includes visible-window startup and rendering checks, binding views and differences, offline editing, native preset hover previews, responsive application, read-only PBZS authentication, and byte-identical GVAS serialization. Save authentication, backup and application safeguards remain in place.

The main download includes the editor and eight preset files. The presets-only archive includes the same layouts and bilingual guide without an executable. Close the game before applying or replacing settings; select Custom 1 in game when using a packaged preset file.
