# PBZKeyForge 1.3.1

Changes since [v1.3.0](https://github.com/muyuanjin/PBZKeyForge/releases/tag/v1.3.0).

- **Less runtime work during play:** reduced repeated ability-binding enumeration, input-pipeline inspection, ledge-protection queries and temporary-equipment scans. Input and scene changes are still checked every frame.
- **More independent moves:** expanded weapon and Phantom Edge entries, including ChiRen attack chains, charged releases and follow-up phases. Move names and related upgrades follow the game's localized labels and are searchable.
- **Independent activation fixes:** repaired One-Eyed Bow preparation and held-input delivery, retained real projectile and charge preparation, and corrected repeated activation for default ability bindings. Held independent Deflect now shares press/release frames across overlapping bindings; ordinary Guard and independently held Stance retain their behavior.
- **Per-binding restriction controls:** equipment, training, ground/air, stance, predecessor and cooldown bypass choices save separately from resource bypass. Supported preparation uses the game's real weapons, effects and projectiles, with restoration when the move ends.
- **Combat settings:** resource bypass includes full-resource release effects; damage and startup/recovery settings follow the current activation and its native continuations. Added optional super armor and invincibility for the current move.
- **Editing and recovery:** improved live-edit feedback, pending-change handling, binding dialogs and catalog refreshes. Keyboard/mouse, Xbox, PlayStation, presets, share codes and exported enhancement libraries preserve the new settings.

## Downloads

Extract the main archive and run PBZKeyForge.exe. To update Key Enhancement, close the game, apply the runtime update in the editor, then restart the game. The included CLI, documentation and eight ordinary preset saves remain available. The presets-only package contains ordinary save layouts, without the editor or enhancement runtime; its layouts are unchanged from 1.3.0. Select **Custom 1** after copying a packaged save.

## Validation and limitations

Regression checks cover overlapping defense inputs through the native defense-state model, move catalogs, settings persistence and sharing, preparation, tuning ownership, cleanup and runtime packaging. Release checks require byte-identical save round trips and preset equivalence. English and Simplified Chinese screenshots show the current editor.

Enhanced combat targets Steam CL-302256 and UE4SS `v3.0.1-1195-g1ceefac8`; ordinary save editing also supports CL-301524. Runtime optimizations address measured hotspots, but this release has no matched post-change in-game FPS measurement. Automated models do not establish every move's animation, damage or target behavior in actual combat. Real targets, hit results and other required gameplay objects remain necessary where documented.
