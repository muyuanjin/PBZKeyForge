# PBZKeyForge 1.2.0

Changes since [v1.1.1](https://github.com/muyuanjin/PBZKeyForge/releases/tag/v1.1.1).

## Binding editor

- Added shared key and action perspectives. The key view combines clickable keyboard and mouse diagrams, shows controller layouts, and opens a key's actions on the right. Action view exposes concrete factory bindings and editable slots using the same draft.
- Added gray factory, blue customized and yellow pending badges. Removed actions have gray icons, strike-through text and a slash so they remain distinct from active mappings.
- Added a full-scheme comparison against saved or factory bindings. Rows can display additions with retained and removed keys, changes only, results only or original bindings.
- Added explicit Unbound choices, concrete factory keys beside Default, and a dedicated keyboard/mouse capture control. Corrected the Chinese Mind's Eye name to 澄心洞照 and represented Shadow Arm with an axe.
- Added resource-derived action and raw-slot defaults for CL-301524, preserving fixed mappings and registered controller-family slot ownership. Capacity feedback explains when an action has no free slot.

## Presets and sharing

- Added named personal presets, separate from built-ins, with previews, batch deletion and export of the current scheme to a game settings file. Saving includes unapplied edits; deleting library entries leaves current bindings intact.
- Reorganized the manager into Save current scheme, My presets, Preset details and Import from share code. The name field receives initial focus; hovering or clicking Save with an empty name prompts for a name.
- Added three directly selectable modes next to preset controls: Add keys, Replace keys and Preset only. The initial mode is Preset only; subsequent launches remember the selection. Hover explanations describe each mode's scope.
- Added PBZ2 share codes containing names and factory-relative additions/removals. Encoding uses protobuf-net, permanent numeric IDs, a frozen baseline, the shorter of raw or DEFLATE data, and Base64URL. Sharing can include keyboard/mouse, controllers or a specific controller family, with a live character count. Applying a scoped preset preserves devices outside its scope.
- Added mouse attack/guard layouts that retain F heavy attack. The automatic-sprint variant binds sprint to W/A/D and dodge/jump to Space while retaining Shift dodge. Eight generated preset saves and their bilingual index match the editor's factory-based previews.

## Responsiveness and validation

- Apply runs in the background with an animated progress indicator. Editing, duplicate application and closing are blocked during the write; failures retain the draft for retry.
- Reuses the executable digest while its path, size and modification time are unchanged, avoiding repeated full-file reads. Key derivation and save authentication still run for each activation.
- Added integration checks for binding relationships, resource defaults, preset formats and scopes, package/editor equivalence, name guidance, native hover, application responsiveness and failure recovery. Routine UI checks use Simplified Chinese; all-language checks are opt-in.
- Added action/device artwork and third-party notices. protobuf-net is embedded in the executables; players need no separate dependency DLL.

## Downloads and use

- `PBZKeyForge-v1.2.0.zip`: editor, eight preset saves, bilingual preset index and documentation.
- `PBZKeyForge-v1.2.0-presets-only.zip`: the same preset saves and instructions, without an executable.

Close the game before applying or replacing settings. The editor backs up writes. Preset selection stages a draft; Apply changes writes it. Preset-only files target Custom 1, which must be selected in game after replacing the file. Avoid applying or resetting bindings in the game's own binding screen afterwards, as it rewrites these settings.

Supported game defaults: Steam CL-301524. Automated checks cover fixture serialization and authenticated writes to isolated copies; combination-skill timing has not been tested in game.

Source and build: https://github.com/muyuanjin/PBZKeyForge. Release archives are built and uploaded by GitHub Actions from the tagged commit.
