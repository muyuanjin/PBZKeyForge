PBZKeyForge 1.3.0 adds optional Key Enhancement: chords, tap/hold, sequences, independent schemes and live binding edits. Bind extra weapon moves, Combat Art finishers and Phantom Edge attacks, with per-binding resource, damage and timing settings. Includes the editor, CLI, eight preset saves and the pinned Kintaro PBZ UE4SS runtime. Enable enhancement and apply with the game closed, then restart. Ordinary save editing remains available. Complete moves retain equipment, upgrade and target requirements; see the included documentation and GitHub release for details.
