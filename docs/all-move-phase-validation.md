# 全招式入口与阶段验证

验证基线为 Steam CL-302256。全部 1,250 个招式目录入口对应 887 个具体能力类；实读继承链共 973 个资源包、1,075 条本地时间线。具体类、原生 InputAction、准备输入、反射回调与阶段选择的时间线均存在于原资源。按 tag 和处决通道选择的入口保留实际装备授予、通道类型及目标条件。

通用能力的 236 个输入标签另经完整 5,728 类 CDO／导出名称和原生激活路径核查，直接目录保留 227 项；九条没有能力实现的输入路线保留审计记录并阻止编译，见[通用能力入口核查](generic-ability-activation-audit.md)。

完整招式目录的 148 条配方逐项记录在 [阶段攻击集合](all-move-phase-validation.json)。其中 56 条保留原生完整激活，45 条交给原生释放／情境回调选择攻击，4 条通过原生处决通道初始化，33 条进入原时间线后自然完成，10 条使用独立阶段的有限结束边界。原生回调的攻击集合列出其条件分支，不表示各分支同时执行。

## 有限阶段

边界均使用原生时间线的 `CurrentTime`，前摇与后摇倍率改变播放速度，不改变选定的攻击集合或结束位置。阶段完整发射、判定并完成相应收招后，由原生 `Move Cancel Ability` 停止阻止移动状态并正常结束本次能力；原能力继续负责蒙太奇、时间线、旋转、位移、标签和装备清理。已发射弹体保留自身生命周期及本次绑定的伤害倍率。

## 持续请求与攻击完整性

同一次活跃能力实例上的独立阶段只进入一次。持续按住不会每帧重播段首，原整套能力的提前取消窗口也不会截断有限阶段尚未完成的攻击。该阶段结束后才接受下一次激活。鬼火的 `activeCallbackOnly` 保留按实际备弹反复扫描的原行为，不重新激活常驻能力。

完整原生战技、普通攻击及已有终结入口保留。阶段边界只限定对应的独立阶段绑定；各自的普通、强化、升级、距离和命中分支继续由游戏选择。

## 验证入口

- [全配方阶段审计器](../build/audit-complete-move-phases.py)：重新读取 148 条配方的实际类、继承时间线、回调、保留与跳过的攻击集合；逐条检查实际攻击首尾，并要求所有移出的后续攻击都由相同原生类、分支的独立末击入口完整保留。
- [阶段资源验证](../tests/AdditionalWeaponPhaseResourceTests.py)：重读 35 个战技类，核对 24 个武器阶段与两个琵琶阶段，以及有限段没有截断任何保留任务、没有纳入后续攻击。
- [编译后阶段验证](../tests/input-router/CompiledWeaponPhaseTests.lua)：执行 26 条阶段、11 个有限原生分支，覆盖倍率、满资源视图、原生费用、活跃实例不重播、按实际时间线结束、配置重置、Buff 消费与弹体倍率保留。

## 已知限制

当前结果属于原游戏资源与本地执行器验证，未启动游戏核对动画衔接、最终扣血或实际资源消费。时间线攻击节点的集合不等同于全部原生伤害回调；按回调选择的分支继续依赖其真实备弹、目标、命中、防反和装备状态。
