# 招式限制与原生准备

绑定设置中的“绕过限制”和“绕过资源”独立保存。启用“绕过限制”后，可以分别选择装备、修行解锁、地面／空中、架势／移动状态、前驱动作、招式冷却。设置随键鼠和手柄绑定、复制、撤销、预设分享与 ZIP 配置包保存。

| 分项 | 执行方式 |
| --- | --- |
| 装备 | 需要指定装备的招式临时使用对应的真实武器配置，创建武器对象并取得原生能力；动作及后续准备完成后恢复原配置。 |
| 修行解锁 | 放开该招式已核对的修行资格。 |
| 地面／空中 | 放开招式的地面、空中资格；招式仍采用游戏自身的位移和动画。 |
| 架势／移动状态 | 放开已核对的架势、冲刺等入口资格。 |
| 前驱动作 | 放开连段入口资格；有独立准备流程的分支按其原生流程初始化。 |
| 招式冷却 | 放开已核对的分身、闪避及特殊闪避冷却资格，保留真实冷却效果和其他操作的资格。 |

各项只作用于本绑定实际请求的能力。原生资格字段在能力模板和角色已持有的能力实例上分别保存，只在同步激活期间临时调整并立即恢复；GAS 的 `CanActivateAbility` 使用已有的主实例时，同样采用本次选择。后续蓝图查询按能力实例保留本次选择，不给玩家全局添加资格标签。伤害、前后摇和资源参数继续随本次动作传递。

直接能力的资格按全部原厂输入来源记录，保留必需与禁止两种条件。角色和能力组件的单项、任一项、全部标签查询均采用本次选择，其他角色和未选择的真实准备状态沿用原结果。同一入口的不同原厂路线若要求相反状态，该状态保留原生分支选择，实际 GAS 激活字段仍按所选类别处理。

临时换装采用目标配置的武器对象与能力，属性仍来自原背包装备。当前动作尚未结束时不会用另一配置替换它。正常结束、关闭增强和运行时重置均恢复原配置；恢复失败时保留原配置用于重试。普通角色动作和可由多个槽位承载的通用动作不任意指定一件装备。

需要拔刀或收刀状态的入口，在选择绕过架势时通过原生 `IsArmed`、`SetArmed` 保存并准备真实武器状态，动作完成后恢复。长刀“风回云卷”的三层增益入口条件属于前驱动作；绕过该项后，炽刃、长形黑伤和共享能力入口均可请求原生攻击，保留各自 `Main` 时间线中的动画、攻击判定与增益消耗回调。实际防反命中和蓄力品质继续使用原生状态。

断肢锯完美防御强化及血锯、妖锯强化、红妆鬼斩增益、偃月刀强化采用原厂 GameplayEffect 准备，保留其中的属性计算、武器效果和 cue。准备按本绑定选择和实际装备过滤；已有同名原生状态时不重复添加。工具仅移除自己创建的效果 handle，失败立即清理，成功则保留至本次攻击及原生后续结束，不清除玩家原有增益。

风回云卷使用原厂三层强化的伤害、武器特效和蓄层显示。需要临时准备三层时，先保存并替换玩家现有的一、二层效果，避免不同层级的伤害修正同时叠加；结束或激活失败后恢复原生效果规格、等级、来源上下文及剩余时间。已自然到期的效果不重新添加，恢复失败保留记录供重试。原三层效果的武器限制及自然消耗流程保留。

白蟒赤练需要投出物的分支，在绕过前驱动作时先发动原生投掷，等待被动能力持有真实弹体及其资格状态，再请求目标招式。已有弹体直接复用；保留武器的原生修行分支、费用及倍率。取消尚未完成的准备时，清理本次创建的投出物。

独眼弓普通射击和死光使用真实的影之武装保持输入。单次触发等待备弹与原生弹体事件完成再松开，实际长按保留更高蓄力档位。凝视的释放窗口保留两个眼球事件，已解锁的千目凝视随原能力生效。千目凝视、凝视、透射的游戏名称及说明可在搜索和招式详情中找到。

荡寇凶刃一波未平、青铜剑与白山风雷剑蓄力、残钢刃蓄势、红妆鬼斩蓄力、破军与偃月刀持续攻击等入口同样传递实际保持输入。单次请求等待原生蓄满或完整攻击，持续绑定保留按住与松开的原生区别。共享能力按真实授予类和当前装备标签选择输入，伤害、独立前后摇及资源参数沿本次激活传递到后续和弹体。输入参数与继承关系见 `native-move-inputs.json`。

持续输入在真实装备及输入处理器准备完成后，由原生桥接构造 `FInputActionValue` 并调用 `StartContinuousInputInjectionForAction`。该结构体的数值和类型没有反射字段，不能经 Lua 表传递；原生 GameplayEffect 上下文同样保留在桥接层内。

锯齿刀命中分支的第二段、结束段可在绕过前驱动作时，从普通战技初始化并播放原生 `HasSawHit` 时间线。斩马刀普通结束段等待原生 `ExecutionTimeline` 初始化。反弹弹体、抓取目标、处决通道、吸收伤害和待发鬼火等实际对象仍由游戏创建；绕过资格不生成虚假的目标、命中或蓄力品质。逐招来源与准备条件保存在 `move-restrictions.json`，装备流程证据见 `weapon-equipment-preparation.json`。

魔剑回收攻击使用被动能力保存的真实弹体及命中次数；满弹状态和已有弹体状态保留原生判断。杀气强化由本次费用与资源计算决定，与前驱动作资格分别处理。

追击位移由原生能力自行寻敌、验证目标 socket、距离和路径，并初始化 MotionWarping。绕过前驱奖励资格仍需真实可达目标。正常资格拒绝和等待输入准备会记录具体招式及原因；正常拒绝可在资格恢复后继续请求。

## 验证范围

游戏资源核对、原生接口桥接测试和路由器模拟验证分别覆盖资格分类、接口双指针及参数布局、分项隔离、输入准备、动作延续和恢复流程。未启动游戏验证，当前结果不包含实机动画、命中与换装表现。
