# 键位增强运行时性能

增强调度逐帧检查当前映射和已应用场景。配置与管线未变化时复用调度关系、原生执行归属和容量验证结果；映射、按键、设备、触发阈值、动作级触发器或场景变化后重新准备。跨帧只保存元数据，不保存原生数组元素的结构包装对象。

原生槽位按动作与设备建立索引，避免每项配置再次遍历全部映射。统一调度下，按键消费只维护到物理释放的锁定状态。文本控件和能力资源通过 UE4SS 对象创建通知加入缓存；焦点、对象有效性及能力触发数组仍逐帧检查。CommonUI 的类和当前玩家子系统在有效期内复用，二维摇杆及其分量每帧共用一次物理读取。

同一物理键的等价连续移动来源共用一次注入。可比较的无状态修饰器包括 Negate、SwizzleAxis、Scalar 和 DeadZone；不同方向、不同参数、时序触发器和独立的有状态修饰器保留各自管线。

绑定的消费键集合、连续来源签名前缀及招式请求身份在创建调度器时计算，配置或动态管线重建时更新。稳定帧直接复用；完整招式仍逐帧请求，由游戏判断能否接续。对象池原地清除失效对象，仅收到创建通知时建立去重集合，稳定帧复用对象列表。

被普通绑定覆盖或显式屏蔽的原厂来源仍保留原生屏蔽和管线信息，但不生成永远不执行的维持规则。解除屏蔽后重新生成对应规则。动态配置重建只编译一次调度器，再按新调度器的按键集合采样并恢复输入状态。

首次启用伤害倍率时，通过三个原生 `FindObjects` 查询取得伤害计算器、Actor 弹体和 Object 弹体；包含派生实例与类默认对象，不再为场景中的每个 UObject 调用 Lua。已有实例和后续创建通知共用伤害跟踪，未启用伤害倍率时不安装伤害钩子。

## 十分钟采样后的运行时优化

2026-11-08 09:39:28–09:49:28 的正式 600 秒窗口中，原生能力屏蔽执行 31211 次，平均 2.517 ms，累计 78.55 秒；映射准备最大 65.365 ms。悬崖保护包含刷新和输入准备两条调用路径，共执行 70075 次，累计约 10.54 秒。阶段相互包含，累计值不能相加为游戏总开销。

能力屏蔽逐帧在原生桥中比较当前资产的绑定数组、条件稀疏映射、六类触发数组与标签字节。稳定时不经 Lua 枚举触发项或转换标签；配置、标签或容器变化时，重新取得当前行完成屏蔽与恢复，再保存观察结果。容器头和拥有指针先于对应分配区比较，变化后停止读取旧分配区。每个资产的观察独立持有，恢复或失效时释放；没有原生桥的模型环境保留原有枚举路径。

映射重建中的当前来源按动作地址分组，仅比较相关动作的管线；触发器及修饰器的类名在本次重建内共用。下一次重建重新读取，阈值修改仍能立即退回原生执行。悬崖保护仅在输入意图改变时追加准备查询，活动资格仍逐帧检查；原生筛选先检查活动计数，再比较冲刺标签。临时装备的保留判断使用同一活动筛选入口，仅在 Lua 中读取活动能力的类，原生后续、持键和待准备动作继续保留装备。

| 模型操作 | 结果 |
| --- | ---: |
| 能力屏蔽连续 120 个稳定帧的额外 Lua 触发器遍历 | 0 次 |
| 原生能力观察连续 2000 个稳定帧的反射查询 | 0 次 |
| 悬崖保护连续 120 个无冲刺输入帧的能力筛选 | 120 次 |
| 130 项授予能力、1 项活动招式的装备保留判断 | 每帧 1 次 Lua 类读取 |
| 130 项非活动能力、10000 次冲刺筛选的标签转换 | 0 次 |

原生桥通过真实 Lua C 调用验证参数消费、返回值和错误清理；引擎对象由模型提供。回归保留原地标签修改、条件稀疏槽、容器重建、失效资产、外部修改后的恢复、招式结束与装备还原，以及资源、伤害、前后摇倍率和保护效果的独立继承。这些结果约束调用次数与生命周期；候选版本的实机收益需另行采样。

无待继承的参数且没有受调参影响的能力实例时，普通原生激活不枚举玩家能力。其他角色的激活不扫描玩家能力；仍在执行的调参招式、原生后续和同帧重试保留各自参数与清理语义。输入的原生归属查询在需要调参时才建立，并随归属记录更新，稳定帧复用结果。

原生上下文桥按 UE4SS 反射取得字段位置，保存映射、场景、按键、设置名称及触发器的比较范围。稳定帧直接比较这些范围，不分配内存或逐行进入 Lua 反射；数组头和拥有者指针先于其分配内容比较，容器或引用变化后立即停止，再由 Lua 重建调度关系。比较不包含触发器每帧变化的输入历史。缺少原生观察入口或布局不受支持时使用 Lua 检查；Lua 路径复用共享名称，并只比较复制的上一帧地址。

配置比较复用工作表，保留原地增删、类型及字段变更检测。48 个映射目标的模型在停止 GC 后运行 1000 个稳定帧，临时配置分配从约 1797 KiB 降至 16 KiB 以下。完整招式按当前已加载类的地址筛选授予项与实例，不为每个无关能力转换完整类名；仍逐次读取当前授予列表，不缓存原生数组元素或缺失的类。

重建时，已解绑映射的设备来源查询复用本次检查得到的默认映射元数据，并在本次调用内复用查询结果。归属计算、容量验证与按键屏蔽不再分别重读所有默认映射；后续帧重新取得当前数据。48 条解绑映射的模型中，默认映射读取从 6960 次降至 48 次，停止 GC 后的单次分配从 4907 KiB 降至 387 KiB；原厂解绑状态、跨设备歧义及场景恢复仍采用原有判断。

旧管线先按动作地址分组，再核对按键、映射名称、触发器与修饰器；每条当前映射不再遍历无关动作的旧管线。80 条映射重新分配后的模型约束动作地址读取次数不超过每条 32 次，并要求复用原有独立管线、不重复克隆；原实现读取 3762 次，超过该界限。

归属计算、输出展开和按键屏蔽复用本次映射检查取得的管线元数据。调度来源与原键恢复使用独立记录，避免观察屏蔽后的按键时改写来源键；原生数组包装不跨帧保存。包含运行时映射和解绑设备默认管线的模型中，每条运行时映射的触发器、修饰器属性读取合计从 8 次降至 2 次。

空闲能力激活钩子在没有调参实例、待继承参数或相关输入时直接返回，不查询玩家组件。伤害对象的四个创建监听仅在首次使用伤害倍率时注册，同一 Mod 生命周期内复用。输入层读取当前 CommonUI 模式和焦点，菜单或剧情退出后无需等待 Blueprint 输入模式回调即可恢复。

暂停或菜单期间，接管恢复成功后不在后续稳定帧重复恢复；重新进入玩法、切换清理方式或恢复失败时重新执行。菜单中的普通改键独立观察当前原生映射与配置，稳定时复用已有原生比较入口，变化时检查本次映射并应用覆盖。连续 120 个暂停帧的模型只在进入时恢复一次；连续 120 个稳定菜单覆盖帧不读取原生映射或默认映射。恢复失败、再次进入菜单、关闭增强、原地修改配置和映射数组重建均有回归覆盖。

普通能力激活没有调参来源时，先检查少量已跟踪实例的活动状态。它们全部活跃时无须恢复旧参数，跳过授予能力列表；存在未激活实例时保留原有选择与恢复逻辑。带调参来源的原生连招仍完整查找目标并继承参数。连续 120 次普通激活的模型不扫描授予列表，同时要求结束前的调参保持有效、未激活实例在普通复用前恢复、失败及嵌套激活正确清理。

## 编辑器后台与实时通信

应用切换到后台时停止火焰动画及待完成的绘制，保留已呈现的背景。主窗口与绑定窗口暂停定期状态查询，重新激活后刷新；同一应用内切换窗口仍保留外观设置的实时预览。

实时协议与输入路由在同一游戏线程串行执行，每 250 ms 检查请求、每秒更新心跳；其余帧只检查轮询时间。UE4SS 的 `LoopAsync` 使用同一 Lua 虚拟机的协程，后台执行未与游戏回调串行化，因此不用于本协议。配置在应用前再次核对请求 ID，取消项不执行；回执写入或关闭文件失败时保留本次结果，下次只补写回执，不重复应用。编辑器等待确认最多 15 秒，忽略不完整回执；超时取消并保留草稿，加载或切回游戏后可重试。

### 默认激活与原生批量筛选

未请求费用、伤害、速度或保护调整，且没有待继承、恢复实例时，激活保留轻量来源边界，不扫描授予列表、不创建默认参数实例状态。来源边界仍阻止同帧其他 InputAction 的参数进入本次显式请求；原生返回值、失败清理、活跃实例和原生后续的参数归属保持各自生命周期。

必要的能力选择由现有原生桥在本次调用内筛选当前授予列表，仅将命中项序号交回 Lua，Lua 再读取当前实例和活动状态。类比较使用地址；标签保持全部/任意、后代边界、重复要求和空集合语义。原生属性布局只在本次扫描内复用，激活前后分别重新查询，迟加载类仍可在原生激活内部解析。没有新增跨帧能力缓存或后台引擎对象访问。

## 配置故障隔离

配置指定的函数、招式入口和弹体查询在调用前检查函数所属类与接收对象；继承方法和已实现的接口均可调用。错误接收对象不会进入该函数的原生调用。

非原生输入输出派发出错后，只停用该目标，记录一次错误堆栈；后续按住或重复触发不再解析资源或执行该目标。延迟招式回调独立处理，清理该目标持有的虚拟输入和由它激活的能力，保留其他招式。重新应用配置或更换玩家后允许重新尝试。原生动作注入、输入释放或故障清理失败时，暂停整个路由并恢复原生输入。

自定义函数 Hook 的注册、条件、计算或返回值解析出错只停用该 Hook；回调错误保留游戏原有返回值。尚未加载的 Hook 每 0.5 个进程 CPU 秒重查一次，重新应用配置时重试失败项。

`RuntimeIsolationTests` 覆盖错误函数接收对象、继承与接口调用、连续 120 帧的故障隔离、Hook 注册和回调错误、单招清理与清理失败升级，以及 2000 帧持续招式不重新拼接静态请求身份。`ObjectPoolTests` 约束稳定帧复用同一对象列表。
