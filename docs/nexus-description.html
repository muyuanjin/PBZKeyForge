PBZKeyForge

A key binding editor for Phantom Blade Zero.

What it does

The game lets you rebind keys, but it will not save a binding where two actions share a key. This tool writes those bindings into the game settings file directly, so one key can do more than one thing.

What you can do

  • Put guard on your attack key, so a click attacks and guards at the same time.
  • Move dodge onto the button that used to guard.
  • Put sprint on Space.
  • Any other combination: 20 actions, three key slots each, keyboard and mouse or gamepad.

What you get

  • PBZKeyForge.exe — the editor. Pick your save, choose a scheme (Default, Custom 1, Custom 2), change keys, save.
  • PBZKeyForge-cli.exe — the same from a command line.
  • Seven ready-made .sav files — copy one over your own file if you would rather not run anything.

Languages: English, Simplified Chinese, Japanese, Korean, Russian. It follows your Windows language, and the toolbar switches it.

Install

With the program

  1. Close the game.
  2. Back up ProjectPBZ/Saved/EnhancedInputUserSettings.sav.
  3. Run PBZKeyForge.exe, press Auto-detect, choose a scheme, apply a preset or set the keys yourself, then Save to file.
  4. Start the game.

With a save file only

  1. Close the game and back up your EnhancedInputUserSettings.sav.
  2. Copy one file from the presets folder over it.
  3. Start the game and select the scheme named in the file.

One thing to know

Do not open the in-game key bindings screen and press apply or reset afterwards. The game rewrites the whole file when it saves, and that removes these bindings. If it happens, apply the preset again.

It also replaces any other mod that ships this file, so use one at a time.

Compatibility

  • Steam version, launch build CL-301524.
  • Windows 10/11. No runtime to install, no UE4SS, no pak files, no DLL.
  • If a game update changes the file format, the tool stops instead of writing bad data.

Uninstall

Put your backup back, or load the Vanilla preset and save.
