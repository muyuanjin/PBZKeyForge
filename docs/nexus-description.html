PBZKeyForge

Put more than one action on the same key.

What this fixes

Phantom Blade Zero refuses to save a binding when two actions share a key. The engine has no such rule: the file is a list of per-action overrides, and two actions on one key fire together. This tool writes that binding into the file, which is the one thing the in-game screen will not let you do.

So the attack button can also guard, the guard button can become dodge, and Space can be sprint.

Source and builds

Code, issues and the build live at github.com/muyuanjin/PBZKeyForge. The executable here is built and uploaded by GitHub Actions from the tagged commit, so you can read the source and see exactly what produced the file you run.

If you would rather not run an executable at all, take the presets-only download. It is nothing but .sav files: copy one over your save and pick that scheme in game.

What you get

  • PBZKeyForge.exe: pick your save, choose a scheme (Default, Custom 1, Custom 2), set keys, save.
  • Seven ready-made .sav files in presets.

20 actions, three key slots each, keyboard and mouse or gamepad. English, Simplified Chinese, Japanese, Korean, Russian: it follows your Windows language and the toolbar switches it.

Install

  1. Close the game.
  2. Back up ProjectPBZ/Saved/EnhancedInputUserSettings.sav.
  3. Run PBZKeyForge.exe, press Auto-detect, choose a scheme, apply a preset or set the keys, then Save to file.
  4. Start the game and make sure that scheme is the active one.

One thing to know

Do not open the in-game key bindings screen and press apply or reset afterwards. The game rewrites the whole file when it saves, which removes these bindings. Re-apply the preset if that happens.

It also replaces any other mod that ships this file, so use one at a time.

Compatibility

  • Steam version, launch build CL-301524.
  • Windows 10/11, no runtime install, no UE4SS, no pak files, no DLL.

Uninstall

Restore your backup, or load the Vanilla preset and save.
